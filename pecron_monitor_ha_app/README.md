# Pecron Monitor HA App

Monitor and control Pecron portable power stations through MQTT discovery
entities in Home Assistant.

- Several units in one app
- Local network, Pecron cloud, or both
- Battery, power and voltage sensors, AC and DC output switches
- Optional energy (kWh) sensors

Requires an MQTT broker such as the Mosquitto broker app. See the
**Documentation** tab for setup.

Unofficial: not affiliated with or supported by Pecron. Built on
[pecron-monitor](https://github.com/attractify-logan/pecron-monitor) by
attractify-logan and contributors.
